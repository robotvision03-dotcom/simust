account that holds the authoritative DNS zone for simust.com.

Whoever can sign in to that Cloudflare account must change the record
manually. Do not ask the website developer to do this.

Current public DNS (still wrong until this is done):
  my.simust.com  A  188.166.104.119
  (webreact.io / DigitalOcean; HTTP 502 Pingora)

Required record:
  Type: A
  Name: my
  IPv4: 157.180.47.98
  Proxy: DNS only — grey cloud
  TTL: Auto

Steps
-----
1. Open Cloudflare → simust.com → DNS → Records.
2. Search for my.
3. Edit the existing A record to the values above.
4. Remove any additional A, AAAA, or CNAME record named my.
5. Send a screenshot showing the filtered my records.

Hetzner host at 157.180.47.98. Until then use:
